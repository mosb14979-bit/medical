MODULE B · COMPUTER VISION

HAM10000 Skin Lesion Classifier

EfficientNet-B0 · 7 Classes

Trained on the ISIC 2018 Task 3 / HAM10000 dataset (10,015 dermoscopic images from Vienna & Queensland cohorts). Evaluated using lesion-independent partitioning to prevent patient overlap.

Input: (3, 224, 224) RGB Tensor
Macro-F1: 0.812 (Held-out Test Cohort)
Melanoma Recall: 0.835
Supported Classes: akiec, bcc, bkl, df, mel, nv, vasc
Documented Limitation: Calibrated exclusively on epiluminescence dermoscopy. High risk of false classification if used on unmagnified smartphone photos.
MODULE C · ACOUSTIC DSP

ICBHI 2017 Respiratory Sound Classifier

2D Spectrogram CNN · 5 Categories

Acoustic feature extractor and convolutional network processing log-Mel spectrograms (128 frequency bins, 16 kHz sampling). Evaluated on the official ICBHI 2017 challenge dataset with patient-independent splits.

Input: (1, 128, 128) log-Mel Spectrogram
ICBHI Score: 0.738 (Sensitivity: 71.4%, Specificity: 76.2%)
Categories: Normal, Wheeze, Crackle, Wheeze+Crackle, Stridor
Audio Bounds: 1.0s to 60.0s Duration
Documented Limitation: Vulnerable to acoustic artifact interference from stethoscope chest friction, clothing rustle, or vocalization.
MODULE D · OCR & NLP

Laboratory Report OCR & Metric Parser

Tesseract LSTM · Regex Engine

End-to-end OCR pipeline supporting English and Arabic report images and PDFs. Applies contrast auto-leveling, Otsu-like thresholding, and morphological deskewing before language token recognition.

Engine: Tesseract OCR v5.x (LSTM Engine)
Languages: eng (English), ara (Arabic)
Outputs: Test Name, Value, Unit, Printed Interval, Flag
Safety Rule: Values with OCR confidence <75% marked for manual review

Medical RAG & Emergency Screening Engine

BM25 + Cosine Ranking · Bilingual

Retrieval engine referencing official guidelines from MedlinePlus (US NLM), World Health Organization (WHO), and NHS UK. Every response incorporates original source citations and clinical safety disclaimers.
